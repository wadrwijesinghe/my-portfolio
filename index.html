Water Quality Monitoring System using ESP32

Technologies: ESP32, pH Sensor, Turbidity Sensor, OLED Display

A smart environmental monitoring solution capable of real-time water quality assessment. The system captures pH and clarity levels, displaying them locally on an OLED screen while simultaneously transmitting data to a web interface for remote environmental tracking.

Designed and developed an IoT-based Water Quality Monitoring System using ESP32 to measure and monitor key water parameters in real time. The system integrates multiple sensors to detect parameters such as pH level, temperature, and turbidity, ensuring accurate assessment of water quality.

Collected data is processed by the ESP32 microcontroller and transmitted to a web-based interface for real-time monitoring and visualization. The system enables continuous tracking, early detection of water contamination, and improved decision-making for environmental and industrial applications.

This project enhanced my skills in embedded systems, IoT development, sensor integration, and real-time data monitoring.

⚙️ Technologies Used:

  • ESP32 & Embedded Systems
  • IoT & Wi-Fi Communication
  • Web Dashboard & Interface
  • Sensors: pH, Turbidity, Temperature

PLC Bottle Filling Automation System

Technologies: Programmable Logic Controller (PLC), Ladder Logic, Simulation Tools

This automation project involved the design, simulation, and implementation of a sequential bottle filling line. Using industry-standard ladder logic programming, the system demonstrates efficient control over conveyor belts, valves, and sensors in a simulated industrial environment.

Designed and implemented a PLC-based Automatic Bottle Filling Conveyor System to automate industrial liquid filling processes. The system uses programmable logic control to manage bottle detection, conveyor movement, and precise filling operations.

Sensors were used to detect bottle position, while the PLC controlled the conveyor motor and solenoid valve to ensure accurate and consistent filling. The system was developed to reduce manual intervention, improve efficiency, and enhance reliability in production environments.

Gained hands-on experience in PLC programming, industrial automation, sensor integration, and control system design.

⚙️ Technologies Used:

  • Siemens PLC & Ladder Logic Programming
  • Photoelectric Sensors
  • Relay Modules & Solenoid Valves
  • Conveyor Motor & Water Pump
  • Industrial Automation Tools
